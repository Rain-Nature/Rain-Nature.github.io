Java改36-注解

Java改
Publish Date:   2026-02-19

1. 注解

1.1 注释和注解的区别？

​ 共同点：都可以对程序进行解释说明。

​ 不同点：注释，是给程序员看的。只在Java中有效。在class文件中不存在注释的。

​ 当编译之后，会进行注释擦除。

​ 注解，是给虚拟机看的。当虚拟机看到注解之后，就知道要做什么事情了。

1.2 Java中已经存在的注解（掌握）

  • @Override：用于标记一个方法重写（Override）了父类或接口中的方法

    作用：让编译器进行重写检查，防止方法名写错，防止参数不匹配

  • @Deprecated：表示被修饰的类、方法或字段已过时，不建议继续使用

    作用：编译时产生警告，提示开发者使用替代方案

  • @SuppressWarnings("all")：用于抑制编译器产生的指定类型警告，例如：拼写检测、变量未使用检测

除此之外，还需要掌握第三方框架中提供的注解：

比如：Junit

​ @Test 表示运行测试方法

​ @Before 表示在Test之前运行，进行数据的初始化

​ @After 表示在Test之后运行，进行数据的还原

1.3 自定义注解（掌握）

自定义注解类的创建

​ 使用IDEA时，创建类，选择Annotation类型

自定义注解的格式
public @interface 注解名称 {

    public 属性类型 属性名() default 默认值;
    
    /*注解中的属性类型只能是以下几种：
    
		基本数据类型（byte、short、int、long、float、double、char、boolean）
		String
		Class
		注解类型
		枚举类型（enum）
		以上类型的一维数组
	*/
}

//例如：
public @interface MyAnnotation {

    String value();

    int age() default 18;

    Class<?> type();

}
自定义注解的使用

​ 注意：使用注解时写在类上还是属性上不是固定的，是由 @Target（元注解）决定的

@注解名(属性名1 = 值1, 属性名2 = 值2)
//类（略）
	
    /* 注意事项

		1.使用自定义注解时，必须为每个没有默认值的属性赋值
		2.如果属性定义了 default 默认值，则可以不赋值
		3.属性赋值时必须使用：属性名 = 值 的形式
		4.如果只有一个属性，且属性名为 value，可以省略属性名，直接写值
	*/

//例如：
@MyAnnotation(name = "张三", age = 18)
public class Demo {
}

1.5 特殊属性-value（掌握）

value：

​ 当注解中只有”一个属性”，并且属性名是”value”，使用注解时，可以省略value属性名

代码示例：日志打印
//注解的定义
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Anno2 {
    String value();   // 日志内容
}

//注解的使用
public class Demo {

    @Anno2("开始执行 method1")
    public void method1() {
        System.out.println("method1 running...");
    }

    @Anno2("开始执行 method2")
    public void method2() {
        System.out.println("method2 running...");
    }
}

//注解的解析-写的一个“简易日志处理器”
public class Runner {
    public static void main(String[] args) throws Exception {
        Demo demo = new Demo();

        //获取Demo的所有方法
        for (Method method : Demo.class.getDeclaredMethods()) {
            //判断是否有注解-@Anno2
            if (method.isAnnotationPresent(Anno2.class)) {
                //获取注解对象
                Anno2 anno = method.getAnnotation(Anno2.class);

                // 打印日志（注解的 value）
                System.out.println("日志：" + anno.value());

                // 执行当前循环的demo对应的方法-对应有注解的method1和method2
                method.invoke(demo);

                System.out.println("执行完成\n");
            }
        }
    }
}
执行结果
日志：开始执行 method1
method1 running...
执行完成

日志：开始执行 method2
method2 running...
执行完成

1.6 元注解（掌握）

元注解的定义

​ 写在注解上面的注解

元注解

​ @Target ：指定注解能在哪里使用

​ @Retention ：可以理解为保留时间(生命周期)

  • Target

    作用：用来标识注解使用的位置，如果没有使用该注解标识则自定义的注解可以使用在任意位置

    可使用的值定义在ElementType枚举类中，常用值如下

    • TYPE，类，接口
    • FIELD，成员变量
    • METHOD，成员方法
    • PARAMETER，方法参数
    • CONSTRUCTOR，构造方法
    • LOCAL_VARIABLE，局部变量

  • Retention

    作用：用来标识注解的生命周期(有效范围)

    可使用的值定义在RetentionPolicy枚举类中，常用值如下

    • SOURCE：注解只作用在源码阶段，生成的字节码文件中不存在
    • CLASS：注解作用在源码阶段，字节码文件阶段，运行阶段不存在，默认值
    • RUNTIME：注解作用在源码阶段，字节码文件阶段，运行阶段，如果要做 AOP 或框架扫描，必须使用 RUNTIME（开发常用）
样例
import java.lang.annotation.*;

/**
 * @Target(ElementType.METHOD)
 * 作用：限定该注解只能写在“方法”上。
 *
 * @Retention(RetentionPolicy.RUNTIME)
 * 作用：指定注解的生命周期
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Myanno1 {

    String value();
    String name();
}

1.7 注解解析-模拟JUnit自带的@Test注解（掌握）

​ 注解单独使用没有意义，必须与解析配合使用

​ 注解的解析：判断是否存在注解，如果存在则解析出注解中的内容

常用注解解析的方法
方法 说明
Annotation[] getDeclaredAnnotations() 获取当前对象上使用的所有注解，返回注解数组
<T extends Annotation> T getDeclaredAnnotation(Class<T> annotationClass) 根据注解类型获取对应的注解对象
boolean isAnnotationPresent(Class<? extends Annotation> annotationClass) 判断当前对象是否使用了指定的注解，使用返回 true，否则返回 false
解析注解的技巧

注解在哪 → 先拿谁的对象 → 再从对象上解析注解

例如：在方法上，就先获取方法对象；在类上，就获取类对象（反射）

代码-模拟JUnit自带的@Test注解
/**
 * 需求：定义若干方法，只要加了@MyTest注解，就可以在启动时执行
 * 分析：1.该注解只能加在方法上，且生命周期一直存在
 *      2.方法上加了@MyTest注解才能触发执行，没加@MyTest的不执行
*/

//MyTest.java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface MyTest {
}

//MyTestMethod.java
public class MyTestMethod {

    @MyTest
    public void method1(){
        System.out.println("method1");
    }

    public void method2(){
        System.out.println("method2");
    }

    @MyTest
    public void method3(){
        System.out.println("method3");
    }
}

//MyTestDemo.java
public class MyTestDemo {
    public static void main(String[] args) throws ClassNotFoundException, IllegalAccessException, InstantiationException, InvocationTargetException {
        //1,获取class对象
        Class clazz = Class.forName("com.itheima.test2.MyTestMethod");

        //获取对象
        Object o = clazz.newInstance();

        //2.获取所有方法
        Method[] methods = clazz.getDeclaredMethods();
        for (Method method : methods) {
            //method依次表示类里面的每一个方法
            //临时修改权限-因为有些方法可能是private
            method.setAccessible(true);
            //判断当前方法有没有MyTest注解
            if(method.isAnnotationPresent(MyTest.class)){
                //执行MyTestMethod对象定义的方法
                method.invoke(o);
            }
        }
    }
}
